```
                    │  幕僚授业，夜读航海图         │
                    │  （诊断测试 / 智能课堂）      │
                    └─────────────────────────────┘
```

五级从「品牌愿景」到「功能动作」逐层下沉，每一级回答一个不同的问题：

| 层级 | 回答的问题 | 一句话角色 | 记忆强度 |
|---|---|---|---|
| **品牌级** | 我们是谁、为何存在 | 精神锚点，门面 | 最高（4+4 对仗，过目不忘） |
| **产品级** | 我们能帮你做成什么 | 价值承诺，转化 | 高（行动句式，利落） |
| **营销级** | 为什么现在、为什么选我们 | 叙事钩子，传播 | 高（郑和 IP + AI，故事化） |
| **用户级** | 你跟什么样的人为伍 | 身份认同，凝聚 | 中（召唤式，社群口号） |
| **功能级** | 这一步对我有什么用 | 场景引导，好用 | 低（具象，即用即懂） |

> **核心原则**：五级共用同一套「郑和航海使团」意象，因此放在一起是同一品牌的多个切面，而不是五个互不相关的口号。上层定调性，下层促行动。

## 二、设计理念：一个 IP 宇宙，五个表达层次

### 2.1 核心隐喻

以 **郑和七下西洋** 为品牌原典，把「中国学生 / 品牌出海」映射为「使团远航」：

- **出海** = 走出国门、跨境经营（用户的最终目标）
- **南洋** = 目标市场（东南亚）
- **使团** = 平台/组织的整体形象（不是单打独斗，而是有组织、有底气）
- **幕僚** = AI 智能顾问（藏在身后的智囊团）
- **探路 / 测风向** = 诊断测试（出发前先摸清路线与天气）
- **航海图** = 系统化知识/题库/方法论
- **授业 / 夜读** = 智能课堂（航行途中掌灯夜读、持续充电）
- **万国来朝** = 目的地世界的繁荣与汇聚（价值感、全球视野）

### 2.2 三个设计杠杆

1. **历史 IP 做信任背书**：郑和在东南亚（印尼、马来西亚、泰国、马六甲等）有广泛的历史记忆与郑和庙/三宝垄等文化遗迹，天然具有区域亲和力——比纯西方商业叙事更贴近「南洋出海局」的目标人群。
2. **对仗句式做记忆点**：品牌级/产品级/功能级均采用 4 字双句对仗，节奏齐整、易读易记，天然适配中文海报与口播。
3. **AI × 航海做差异化**：把"AI"安插进航海叙事（AI 测风向 / AI 跨境出海新局），将抽象技术转译为具象动作，降低理解门槛。

## 三、五级详解

### 3.1 品牌级 —— 精神主张

> **扬帆南洋，智驭四海**

| 项 | 说明 |
|---|---|
| **解析** | 扬帆（行动）＋ 南洋（目标区域）／ 智驭（AI 智慧驾驭）＋ 四海（全球化格局） |
| **回答** | 我们是谁、为何存在 |
| **适用场景** | 首页 Hero、品牌官网首页、社媒简介（bio）、品牌 PPT 封面、官网 `<title>`/`description`、名片 |
| **语气** | 宏阔、凝练、自信、有气魄 |
| **使用规范** | 品牌级是"门面"，**单独使用**，不与产品级/功能级堆叠；文案周边留白，配合大视觉 |
| **慎用** | 不用于功能按钮、活动横幅等短时触点的正文 |

### 3.2 产品级 —— 价值承诺

> **使团幕僚，一键出海**

| 项 | 说明 |
|---|---|
| **解析** | 使团（有组织的平台）＋ 幕僚（AI 智囊团）／ 一键（极致易用）＋ 出海（达成目标） |
| **回答** | 我们能帮你做成什么 |
| **适用场景** | 产品功能页、下载页、应用商店截图标题、信息流广告、落地页首屏 |
| **语气** | 干练、务实、可信，偏"功能达成"而非"精神感召" |
| **使用规范** | 通常与 1–3 个功能亮点并列使用（如"使团幕僚，一键出海——AI 诊断 + 智能课堂 + 学习计划"），形成价值闭环 |
| **慎用** | 不用于发布会/宣传片的主文案（那是营销级的职责） |

### 3.3 营销级 —— 叙事钩子

> **复刻郑和七下西洋之智，开启 AI 跨境出海新局**

| 项 | 说明 |
|---|---|
| **解析** | 复刻（承袭历史）＋ 郑和七下西洋（超级 IP）＋ 之智（古人的智慧）／ 开启（新时代）＋ AI 跨境出海（技术+目标）＋ 新局（与旧时代对照） |
| **回答** | 为什么现在、为什么选我们 |
| **适用场景** | 宣传片/品牌片主文案、PR 新闻稿首段、产品发布会 Keynote 主视觉、媒体通稿标题 |
| **语气** | 叙事性、宏大、有历史纵深感，讲"从七下西洋到 AI 出海"的跨越 |
| **使用规范** | 面向有叙事空间的长内容；可作为 PR 标题或发布会金句；**不做**短时横幅/按钮文案 |
| **慎用** | 长度较高，不用于 Logo 旁、导航、弹窗等紧凑空间 |

### 3.4 用户级 —— 身份认同

> **入局出海，万国来朝**

| 项 | 说明 |
|---|---|
| **解析** | 入局（加入行动，强调参与）＋ 出海（共同目标）／ 万国（全球市场与伙伴）＋ 来朝（繁荣汇聚的获得感） |
| **回答** | 你跟什么样的人为伍 |
| **适用场景** | 用户社群（群公告、每周话题）、活动海报、直播开场/结尾、线下聚会主题、会员计划名称 |
| **语气** | 亲和、召唤、有归属感，可以口语化 |
| **使用规范** | 常与"我们正在出海"类内容搭配，把用户代入"船上的一员"；适合做成社群口号/接龙话题 |
| **慎用** | 不用于需要冷静、权威语气的场合（如隐私政策、客服话术） |

### 3.5 功能级 —— 场景微文案

> **出海先探路，AI 测风向**（诊断测试）
> **幕僚授业，夜读航海图**（智能课堂）

| 项 | 说明 |
|---|---|
| **解析** | 诊断测试：先探路（先摸清现状）＋ AI 测风向（AI 评估方向与强弱项）；智能课堂：幕僚授业（AI 当老师）＋ 夜读航海图（随时随地学习系统知识） |
| **回答** | 这一步对我有什么用 |
| **适用场景** | 诊断测试入口/加载页/结果页头图、智能课堂入口与课件页、功能引导（onboarding）、空状态、推送通知标题、课堂打卡分享卡 |
| **语气** | 具象、易懂、点到即止，配合一句话功能说明（如"10 分钟摸清你的强弱项"） |
| **使用规范** | 功能级是**锦上添花**，不抢主视觉；每条功能 slogan 与具体的功能按钮/页面标题并存，保证可理解性 |
| **延展** | 后续每个新功能都可按同法生产，如就业辅导 →「使团引路，登岸安家」等（词库见第六节） |

## 四、场景配比规则

**一个触点，一个主 Slogan；功能级只做引导性补充。**

| 触点 | 首选层级 | 用法 |
|---|---|---|
| 首页 Hero | 品牌级 | 大字号主视觉，独占 |
| 品牌官网"关于我们" | 品牌级 | 配合品牌故事长文 |
| 功能页（诊断/课堂/计划） | 产品级 | 页面顶部价值句 |
| 应用商店 / 下载页 | 产品级 | 标题用产品级，截图配功能级 |
| 信息流广告 / 落地页 | 产品级 | 与卖点列表搭配 |
| 品牌宣传片 / 发布会 | 营销级 | 开场金句 + 品牌级收尾 |
| PR 通稿 | 营销级 | 标题/首段 |
| 用户社群 | 用户级 | 群公告、话题标签 |
| 活动海报 | 用户级 | 主文案 + 品牌级角标 |
| 诊断测试入口 | 功能级 | 入口按钮 + 微文案 |
| 智能课堂入口 | 功能级 | 入口按钮 + 微文案 |
| 推送通知 / 打卡分享 | 功能级 | 短句 + 用户级语气兜底 |

> **配比口诀**：品牌级管"信任"，产品级管"转化"，营销级管"传播"，用户级管"凝聚"，功能级管"好用"。同一页面尽量只出现一个"主口号"，避免五级全上导致失焦。

## 五、语气与调性规范

| 层级 | 调性关键词 | 句式特征 | 禁忌 |
|---|---|---|---|
| 品牌级 | 宏阔 · 凝练 · 自信 | 4+4 对仗或短句，书面化 | 口语词、emoji、夸张感叹 |
| 产品级 | 干练 · 务实 · 可信 | 行动导向，"一键/快速/搞定" | 空泛形容词、过度承诺 |
| 营销级 | 叙事 · 宏大 · 历史感 | 完整长句，起承转合 | 平铺直叙、无记忆点 |
| 用户级 | 亲和 · 召唤 · 归属 | 第二人称"你/我们"，可口语 | 说教感、命令式 |
| 功能级 | 具象 · 易懂 · 点到为止 | 4+4 对仗 + 一句说明 | 术语堆砌、与主视觉抢戏 |

## 七、多语言与跨文化落地建议

1. **郑和在东南亚具有天然认知度**：印尼三宝垄、马来西亚马六甲等地留有郑和遗迹与传说，是品牌出海的天然文化桥梁——多语言版本优先强化这一点，而非强行翻译成西方叙事。
2. **对仗句式不可直译**：中文 4+4 对仗的节奏感在英/泰/越/印尼语中无法复制。建议策略为 **中文原句保留 + 目标语意译**（而非逐字翻译），品牌官网上双语呈现。
3. **各语言意译方向**：
   - 品牌级 "扬帆南洋，智驭四海" → EN: *Setting sail across Nanyang, navigating the world with AI.*
   - 产品级 "使团幕僚，一键出海" → EN: *Your AI mission staff — go global in one tap.*
   - 用户级 "入局出海，万国来朝" → EN: *Join the voyage. The world awaits.*
4. **本地化禁忌**：东南亚部分市场对"朝贡/来朝"等字眼的王朝感需审慎评估，出海至印尼/马来西亚/越南时可在用户级文案中弱化为"汇聚/同行/共赢"。

| 层级 | 规格 | 落地 class | 用途 |
|---|---|---|---|
| Hero | 36-48px | `text-4xl md:text-5xl` + `font-brand-title` | 首页 Hero、案例页 Hero |
| 模块标题 | 24-28px | `text-2xl` + `font-brand-title` | 模块 h2/h3（首页流程/课堂、csca 当前步骤/候选信息/AI 讲解、案例页模块） |
| 卡片标题 | 18-20px | `text-lg`（保持正文文楷，不加 title） | 卡片标题（按用户决策不套标题字体） |
| 正文 | 14-16px | `text-sm` / `text-base`（继承 `font-brand-body`） | 正文、说明 |
| 辅助文字 | 12px | `text-xs` + `font-brand-pixel`（装饰类） | 标签、chip、成就名、页脚胶囊 |

### 10.3 使用规范

- **标题字体只用于 Hero + 模块标题**（h1/h2 + 显著模块 h3）；卡片标题保持正文霞鹜文楷。
- **英文/数字 `font-brand-eng`**：仅包数字/字母本身，**不可**套在含中文的整段 span 上——Press Start 2P 无 CJK 字形，中文字符会回退到 monospace 而非文楷。混合标签（如「匹配度 85%」）容器用 `font-brand-pixel`，其中纯数字用嵌套 span 包 `font-brand-eng`（per-glyph 回退兜底）。
- **像素 `font-brand-pixel`**：用于特殊标签、成就名称、错题标签、学科/难度 chips、页脚胶囊等 `text-xs` 处（12px 与像素字体天然匹配）。

### 10.4 范围决策

- **应用**：4 个品牌页（首页 `/`、备考中心 `/csca`、幕僚厅 `/csca-multi-agent`、案例页 `/csca/case-study`），由 `.brand-light` 作用域承载。
- **不应用**：课堂生成器系（`generation-preview`/scene-renderers/roundtable/classroom/eval）保持 Geist/Inter 不变；全局 `body`/`:root` 字体栈未动。

### 10.5 Zpix 子集维护

Zpix 原始 TTF 约 7MB，按「4 个品牌页 + `lib/i18n/translations.ts` + `lib/i18n/locales/zh-CN.json` 实际出现字符」子集化（1360 字）后仅 ~46KB。**新增文案超出既有字符集时，需重跑**：

```bash
python scripts/subset-zpix.py [zpix.ttf 路径]
```

输出覆盖 `public/fonts/zpix.woff2`。LXGW 文楷为 97 个 unicode-range 子集，覆盖全套 CJK，无需再生成。
